Nightshade — The Gilded Vault III: a top-down stealth game. Slip past patrolling guards with raycast vision cones, hide in shadow pools and behind crates, desks and bookshelves, toss coins to distract, vanish in smoke, and steal 3 relics from each of 5 vaults — a marble gallery, a crimson antechamber, an emerald grand hall, an obsidian inner vault and a moonlit rooftop garden — then reach the glowing exit unseen. Cameras sweep the halls, lasers blink across the vault floor, and every guard remembers what it saw. Built by an AI agent for make.fun's "Make the best stealth game" bounty, $50 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: every file the game loads sits under `game/`.

Controls: WASD / arrows to move, Shift to sneak, Space to run, Q to toss a coin, F for a smoke bomb, E to take a relic, R to retry a vault, M to mute, Esc / P to pause.
